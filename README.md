"Solara Bay" is a complete 3D open-world crime game in the browser — a sun-soaked coastal city to explore on foot and by car, with traffic and pedestrians, cars to steal, a wanted level with police who respond, 4 story missions, combat, a HUD with a minimap, a start screen and a save. Built with three.js, all original names, story, art and sound.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080
